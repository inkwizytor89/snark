# Decision: distributed documentation

Documentation should stay distributed across the most specific document for each topic.

Overviews must stay brief and general. If a topic is documented in detail elsewhere, the overview should link to that exact location instead of repeating the explanation.

This keeps the documentation single-purpose, reduces duplication, and makes the detailed source of truth easy to find.

Rules:

- Keep repeated descriptions out of multiple documents.
- Use short summaries in index or overview pages.
- Link directly to the detailed document when exact behavior is needed.
